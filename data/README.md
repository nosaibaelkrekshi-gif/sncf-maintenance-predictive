# Données

Les données ne sont pas stockées dans ce dépôt : le notebook les télécharge automatiquement depuis le portail open data de la SNCF, via son API.

| Jeu de données | Contenu | Lien |
|---|---|---|
| Régularité mensuelle TGV nationale | Régularité et ponctualité des TGV, mois par mois, depuis 2015 | [ressources.data.sncf.com](https://ressources.data.sncf.com/explore/dataset/reglarite-mensuelle-tgv-nationale/) |
| Régularité mensuelle TGV par liaison | Retards, annulations et causes des retards par liaison, depuis 2018 | [ressources.data.sncf.com](https://ressources.data.sncf.com/explore/dataset/regularite-mensuelle-tgv-aqst/) |
| Fréquentation des gares | Nombre annuel de voyageurs par gare, 2015-2024 | [ressources.data.sncf.com](https://ressources.data.sncf.com/explore/dataset/frequentation-gares/) |

Licence : **Open Database License (ODbL)**. Les données sont publiées par la SNCF et utilisées ici dans un cadre académique, avec attribution de la source.

Pour garantir la reproductibilité, l'analyse a été figée au **31 mars 2026** (12 181 lignes pour les liaisons, 135 mois pour la régularité nationale).
